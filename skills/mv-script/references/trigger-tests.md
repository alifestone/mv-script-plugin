# 觸發測試

驗證 `SKILL.md` 的 `description` 有沒有在對的時候觸發、在不對的時候不觸發。
做法借自 yao-meta-skill 的觀念：先列「應觸發」與「不應觸發」的句子，改 description 後逐句重測。

用法：把句子逐一丟給沒有任何上下文的 Claude，看它會不會載入 `mv-script`。改 description 後全部重測。

## 灰區（觀察，不列入通過條件）

| 句子 | 預期 | 備註 |
| --- | --- | --- |
| 幫我寫一首歌的歌詞 | 不觸發 | 寫歌詞不是劇本流程 |
| 把這支分鏡表轉成 Markdown | 視情況 | 若是 plan 目錄的 YAML → 觸發；若是別的格式 → 不觸發，先確認 |
| 幫我想 MV 的概念 | 觸發 | 流程步驟 2 |
| 用 AutoMV 或 ViMax 生成 MV | 不觸發 | 那是其他工具的使用；本外掛只借它們的方法 |

## 通過標準

- 應觸發 10 句至少 9 句載入。
- 不應觸發 10 句全部不載入。
- 改 `description` 之後，兩張表全部重測，結果記在這份檔案下方（日期、通過數、失敗句）。
